# Handwritten Math to LaTeX

A deep learning project that converts handwritten mathematical expressions into their corresponding LaTeX representation.

The system takes an image of a handwritten equation as input and generates a structured LaTeX sequence as output. It uses an image-to-sequence architecture with a visual encoder, attention mechanism, and sequence decoder to capture both mathematical symbols and their spatial relationships.

## Dataset

- CROHME (Competition on Recognition of Online Handwritten Mathematical Expressions)

## Core Technologies

- Python
- PyTorch
- CNN-based visual encoding
- Attention mechanisms
- LSTM / Transformer-based sequence decoding
- LaTeX tokenization

## Goal

Build an accurate handwritten mathematical expression recognition system capable of converting complex handwritten equations into valid LaTeX code.
